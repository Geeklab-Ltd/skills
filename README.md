## Why we share these skills

We’re sharing useful workflows from the work of building and growing apps. This collection brings together general skills for **app store optimization (ASO)**, **user acquisition (UA)**, **app marketing**, **design**, and **development**, along with supporting research, writing, and everyday workflows.

A skill gives an AI agent a focused set of instructions, examples, and, when needed, supporting scripts or reference files. Use these packages to turn a brief into a clearer plan, create useful assets, or carry out a repeatable task with your own tools.

Our aim is simple: make practical knowledge easier to find, install, and use. These are public packages you can install directly from GitHub. You do not need a Geeklab account or Geeklab MCP connection.

### What belongs here

- **ASO:** store listings, positioning, keywords, screenshots, and creative testing.
- **User acquisition:** campaign planning, advertising creatives, testing, and performance analysis.
- **App marketing:** launch planning, messaging, content, and growth workflows.
- **Design & creative:** app icons, visual assets, and creative production.
- **Development:** implementation, integrations, and the technical work needed to build and ship apps.

These describe the collection’s scope. The directory above shows what is available today.

## Installation

With Node.js and npm installed, run:

```sh
npx skills add 'https://github.com/Geeklab-Ltd/skills'
```

Follow the installer prompts to choose the skills, a supported AI app, and the installation location. To install one skill directly, use the command in that skill’s README. See the [skills installer documentation](https://github.com/vercel-labs/skills) for supported apps and installation options.

Read each skill’s README before using it. Some workflows need image generation, local command execution, developer tools, or third-party accounts. Installation supplies the skill package; it does not add those capabilities or accounts to your AI app.

## Using a skill

1. Open its README from the directory and check its requirements.
2. Install the complete package, including any scripts, references, and assets.
3. Tell your agent which skill to use and provide the brief, files, and constraints it asks for.
4. Review the result and complete any project integration or platform checks described by the skill.

Each package lives under `skills/<skill-name>/` and includes `SKILL.md` and a public `README.md`. Supporting files keep their relative paths so the documented workflow travels with the skill.

## How the collection stays organized

Public releases are reviewed before publication. When a skill is published or updated from Geeklab Skills, its complete package, directory entry, and this README are updated together. The directory uses the reviewed category and metadata; ASO and UA workflows receive their own sections within the marketing collection.

The directory lists published packages only. Private skills and unpublished submissions are not included.
